# Project Roadmap & Future Enhancements

## Completed Milestones

- [x] **Milestone 1 (`v1.0-scaffold`)**: Database schema, SQLAlchemy 2.0 ORM models, Alembic migrations, & JWT authentication.
- [x] **Milestone 2 (`v1.1-rules-solver`)**: Hard & soft constraint rules engine, Google OR-Tools CP-SAT solver, & REST endpoints.
- [x] **Milestone 3 (`v1.2-frontend`)**: React 18 + TypeScript + FullCalendar frontend single-page app scaffold.
- [x] **Milestone 4 (`v1.3-editor`)**: Advanced interactive schedule editor with drag-and-drop, Undo/Redo history stack, & live conflict inspection.
- [x] **Milestone 5 (`v1.4-celery-jobs`)**: Asynchronous Celery task processing with Redis broker and status polling endpoints.
- [x] **Milestone 6 (`v1.5.0`)**: Complete project documentation, ADRs, GitHub templates, and production integration release.

---

## Planned Future Enhancements

- [ ] **PDF / Excel Export Engine**: Export monthly schedules into multi-tab formatted Excel spreadsheets and printable PDFs.
- [ ] **Shift Swap Requests**: Self-service employee portal allowing staff to request shift swaps with manager approval workflows.
- [ ] **Push / Email Notifications**: Automated SMTP notifications informing workers when new monthly schedules are published.
- [ ] **Multi-Tenancy Support**: Support multi-department scheduling isolated across distinct organizational tenants.
