# Coding Standards & Guidelines

## Python Backend Standards
* **Style**: PEP 8 compliance enforced via Flake8.
* **Type Hints**: Explicit Python 3.12 type annotations for all function parameters and return types.
* **Docstrings**: Google-style docstrings for public classes and services.
* **Async**: Use async FastAPI endpoints for non-blocking I/O operations.

## TypeScript Frontend Standards
* **Style**: Strict TypeScript compilation (`"strict": true` in `tsconfig.json`).
* **Components**: Functional components with explicit Props interfaces.
* **Styling**: Tailwind CSS utility classes. Avoid inline style attributes.
